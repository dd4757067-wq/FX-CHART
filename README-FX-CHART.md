# FX CHART

Run locally:

    cd ~/Desktop/DURJOY-FX-WEBSITE
    python3 -m pip install -r requirements.txt
    python3 app.py

Open:

    http://127.0.0.1:5000

Features included:
- FX CHART branding
- TradingView Advanced Chart
- User registration/login with password hashing
- Custom profile + profile photo
- Bio, experience, strategy, hobbies, education, goals and social links
- Learning Center from beginner to advanced
- Candlestick curriculum
- Technical analysis curriculum
- SMC / price action curriculum
- Multi-timeframe curriculum
- Live class architecture
- Subscriber/owner publishing permission
- Community posts, likes and comments
- Subscription records
- Broker connection profiles
- Trading journal
- Analytics
- Risk calculator
- Support/help chatbot
- News/provider-ready page

Important:
- TradingView chart is live charting; broker execution is separate.
- Real Binance/MT5/Exness/XM API trading needs official credentials, provider-specific APIs and secure server-side storage.
- Real payment collection needs a payment gateway and verified credentials.
- Real economic news needs a licensed/current provider. No fake live news is used.
